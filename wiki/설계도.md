# 설계도 — 브랜드 상품 나스 저장 도구

작성일: 2026-10-23
상태: 설계 중. 아직 아무것도 만들지 않음.
표기: 따옴표 안은 내 말 원문. 끝에 (제안)이 붙은 것은 Claude가 제안한 것으로 아직 내가 확정하지 않음.

---

## 1. 이름

- 정한 적 없음.
- 앱 창 제목이자 도구 이름으로 **"나스에 저장"** (제안)
- 문서상 긴 이름은 "브랜드 상품 나스 저장 도구" (제안)

## 2. 누가 쓰나

- "회사 누구나 쓸 수 있는 도구로 만들 거야."
- 첫 사용자는 썸네일·상세페이지·자사몰 배너를 만드는 웹디자인 담당자. 규칙이 그 파일들에만 있기 때문 (제안)
- Windows PC 기준. 맥 사용자가 있으면 만드는 방식이 달라지므로 먼저 확인 (제안)

## 3. 어떻게 시작하나

- "A. 바탕화면 앱에 끌어다 놓는 방식으로 하자."
- 새 파일 저장: 바탕화면 앱 창에 파일을 끌어다 놓으면 시작된다. 버튼도, 문장 입력도, 시트 기입도 없다.
- 기존 파일 일괄 정리: 앱 안에서 "폴더 정리" 메뉴로 나스 폴더 하나를 고르면 시작된다 (제안)
- 설치 없이 실행되는 exe 하나를 나스에 두고, 각자 바로가기로 연다 (제안)

## 4. 안에서 어떤 순서로 만들어지나

첫 버전에는 AI 판단이 들어가지 않는다. 모든 단계가 **사람** 아니면 **도구(규칙)** 이다. 규칙이 문서와 나스에 이미 있어서 추측할 게 없기 때문 (제안)

### 4-1. 썸네일 · 자사몰 배너 · 팝업 (psd 1개 + 내보낸 이미지 몇 개를 한 묶음으로)

| 순서 | 누가 | 하는 일 |
|---|---|---|
| 1 | 사람 | psd와 png·jpg·gif를 앱 창에 끌어다 놓는다 |
| 2 | 도구 | 창을 띄우고, 나스 폴더를 읽어 브랜드·제품 목록을 채운다. 지난번 고른 값을 기본으로 둔다 (제안) |
| 3 | 사람 | 브랜드, 제품, 작업 종류, 채널(썸네일만), 이름을 고르거나 적는다. 자사몰 배너는 이름 대신 위치(mb/pb/lowmb/lowpb)와 순서번호 |
| 4 | 사람 | "문구·가격·오타만 고침"(r) 인지 "디자인 방향이 바뀜"(v) 인지 고른다 |
| 5 | 도구 | 날짜를 정하고(v면 오늘, r이면 원래 v의 날짜 유지 (제안)), 사이즈를 이미지에서 읽고, 나스 폴더를 보고 다음 v/r 번호를 매긴다 |
| 6 | 도구 | 저장될 이름, 저장될 위치, `x/`로 옮겨질 파일을 미리 보여준다 |
| 7 | 사람 | 확인하고 [저장]을 누른다 |
| 8 | 도구 | 나스에 복사하고, 밀려난 이전 버전을 `x/`로 옮기고, 한 일을 기록에 남긴다 |

### 4-2. 상세페이지 (섹션 전체를 한꺼번에)

- "네. 상세페이지는 포토샵에서 이미 01_인트로 식으로 이름을 붙여서 저장하고, 전체를 한꺼번에 끌어다 놓을 거야. 도구는 정리와 배치만."

| 순서 | 누가 | 하는 일 |
|---|---|---|
| 1 | 사람 | 섹션 psd와 내보낸 이미지 전체(수십 개)를 앱 창에 끌어다 놓는다 |
| 2 | 사람 | 브랜드, 제품을 고른다. 작업 종류는 `01_` 식 이름을 보고 도구가 "상세페이지"로 미리 골라 둔다 (제안) |
| 3 | 도구 | 파일마다 나스와 비교해 다섯 가지로 나눈다: 변경 없음 → 건너뜀 / 이름 다듬음(`_r1`→`_r01`, 언더바·공백, `(gif)` 꼬리표 제거) / 내용 바뀜 → 다음 `r` 부여, 기존은 `x/` / 새 파일 → 그대로 / 섹션명 없음 → 보류 (제안) |
| 4 | 도구 | 목록으로 보여준다. "저장 n · 건너뜀 n · 보류 n" |
| 5 | 사람 | 목록을 보고 [저장]을 누른다. 보류된 파일은 이름을 붙여 다시 넣는다 |
| 6 | 도구 | 나스에 복사하고, 밀려난 파일을 `x/`로 옮기고, 기록에 남긴다 |

### 4-3. 기존 파일 일괄 정리

- "기존 파일도 도구로 일괄 정리하고 싶어. 다만 바꾸기 전에 목록을 보고 승인할 수 있게."
- "예시로 보여준 기본 규칙 이대로 하자. 날짜는 수정일, 사이즈는 이미지에서, 번호는 v로, 첫 버전도 _v1."

| 순서 | 누가 | 하는 일 |
|---|---|---|
| 1 | 사람 | 앱에서 나스 폴더 하나를 고른다 |
| 2 | 도구 | 폴더 안 파일마다 "이 이름 → 이 이름, 이 위치"를 만든다. 날짜가 없으면 파일 수정일, 사이즈가 없으면 이미지(또는 psd 머리글)에서, 같은 줄기가 여러 개면 번호 순으로 v1·v2·v3를 매기고 최신만 남기고 나머지는 `x/`. 첫 버전에도 `_v1` |
| 3 | 도구 | 추측이 불확실한 파일(섹션명 없는 `01.psd`, 짝 없는 옛 psd 등)은 바꾸지 않고 "사람이 볼 것"으로 표시한다 |
| 4 | 사람 | 목록을 보고 항목별로 승인·제외하고, v를 r로 바꿀 수 있다. 승인한 것만 실행된다 |
| 5 | 도구 | 실행하고, 원래 이름·위치와 바뀐 이름·위치를 기록에 남긴다. 되돌리기 가능 |

## 5. 결과물

- 모양: 규칙대로 이름 붙은 파일. psd 원본과 내보낸 이미지는 같은 이름.
  - 썸네일·팝업 `YYMMDD_이름_WxH_vN[_rNN]`
  - 상세페이지 `NN_섹션명[_rNN]` (`00_`은 순서 밖 상단 배너)
  - 자사몰 배너 `YYMMDD_브랜드_mb|pb|lowmb|lowpb_NN_WxH[_vN][_rNN]`
- 어디로: 나스 `\\SynologyNas\브랜드 상품` 아래, 나스에 이미 있는 골격 그대로.
  - "나스에 있는 골격을 그대로 도구의 기준으로 삼자. 갈림길 세 곳도 제안한 기본값대로."
  - 브랜드 › `01. 상품` › (제품, 둘 이상일 때만) › `썸네일`(+채널 하위폴더 5개) / `상세페이지` / `상세페이지 소스`(옆에)
  - 브랜드 › `03. 자사몰` › `메인배너` / `하단 2분할 배너` / `팝업` (번호 없이)
  - 밀려난 이전 버전은 같은 폴더의 `x/`로. 폴더에는 현재 버전만 남는다. (내 선택: "B")
- 한 번에 몇 개:
  - 썸네일·배너·팝업: psd 1개 + 이미지 1~3개를 한 묶음
  - 상세페이지: 섹션 전체. 나스 기준 20~85개
  - 일괄 정리: 폴더 하나 단위
- 첫 버전 범위: "첫 버전은 썸네일, 상세페이지, 자사몰 배너·팝업까지. 프로모션과 패키지·로고·서류는 다음에."

## 6. 언제 도나

- 일할 때 옆에서. 사람이 파일을 끌어다 놓거나 폴더 정리를 누를 때만 돈다.
- 혼자 정해진 시간에 도는 기능은 없다. 나중에 "규칙에 어긋난 파일 보고서"를 주기적으로 뽑는 건 붙일 수 있음 (제안)

## 7. 사람이 꼭 눈으로 보는 곳 · 누가 승인하나

- 새 저장: 저장 직전의 미리보기(저장될 이름, 위치, `x/`로 옮겨질 파일). 끌어다 놓은 사람이 [저장]으로 승인한다.
- 상세페이지: 파일별 목록(건너뜀 / 이름 다듬음 / r 부여 / 새 파일 / 보류). 끌어다 놓은 사람이 승인한다.
- 일괄 정리: "바꾸기 전에 목록을 보고 승인할 수 있게." 항목별 승인·제외·v↔r 수정 후 실행.
  - 일괄 정리의 승인자는 정하지 않음. 폴더 규칙을 합의한 웹디자인 담당자 1명으로 (제안)
- 눈으로 봐야만 하는 판단 두 가지는 도구가 대신하지 않는다: "디자인이 바뀌었나, 문구만 고쳤나"(v/r), 그리고 옛 파일의 번호가 v인지 r인지.

## 8. 절대 안 되는 것

- 승인 없이 기존 파일을 바꾸거나 옮기지 않는다. ("바꾸기 전에 목록을 보고 승인할 수 있게.")
- 파일을 삭제하지 않는다. 밀려난 파일은 `x/`로 옮기기만 한다 (제안)
- 같은 이름이 이미 있으면 덮어쓰지 않고 다음 번호를 올린다 (제안)
- 섹션명이 없는 파일에 이름을 지어내지 않는다. 보류로 돌려준다 (제안)
- `x/` 말고는 새 폴더를 만들지 않는다. 브랜드·제품 폴더는 나스에 있는 것만 고를 수 있다 (제안)
- 기록 없이 실행하지 않는다. 모든 복사·이동·이름 변경은 되돌릴 수 있게 남긴다 (제안)
- 나스 밖(클라우드, 외부 서비스)으로 파일을 보내지 않는다 (제안)

## 9. 필요한 도구 · 계정 · 비용

- 나스 접근: 각자 PC에서 이미 쓰는 Windows 계정으로 `\\SynologyNas\브랜드 상품`에 접속. 새 계정 없음.
- 앱: 설치 없이 실행되는 exe 1개를 나스에 둔다 (제안)
- 외부 서비스, API, 구독 없음. AI 호출도 없어서 비용 0원 (제안)
- 나스 주소는 설정에 `\\SynologyNas\브랜드 상품`을 기본으로 두고 바꿀 수 있게. 노션에 "추후 변경될 수 있음"이라 적혀 있음 (제안)

## 10. 결과를 받는 곳 · 누구에게 알리나

- 결과는 나스 폴더 자체. 별도 전달 없음.
- 저장이 끝나면 앱이 저장된 경로를 보여주고 클립보드에 복사해 둔다. 디자인 프로세스 문서의 "완성 파일 나스 경로를 시트에 기입" 단계에 바로 붙여 넣을 수 있게 (제안)
- 단톡방·노션 알림은 첫 버전에 없음 (제안)
- 기록 파일은 나스의 `브랜드 상품` 바로 아래 숨김 폴더에 쌓는다 (제안)

## 12. 아직 모르는 것

- 도구 이름
- 입력 창 초안과 저장 동작 세 가지(날짜는 v면 오늘·r이면 유지, 변경 없는 파일 건너뜀, r은 도구가 부여)에 대한 내 확인 — 열네 번째 질문, 답 대기 중
- 일괄 정리의 승인자
- 맥 사용자가 있는지
- 나스 주소가 바뀔 예정인지, 다른 PC도 `\\SynologyNas`로 접속되는지
- 예외 폴더 처리: 온타웨이브는 썸네일이 `03. 자사몰` 아래, 엠서티프라임은 제품 층 대신 `상세페이지\본품 상세페이지`·`하이드로겔 상세페이지`
- 다음 버전으로 미룬 것의 규칙: 프로모션 폴더명 `YY.MM_이름` 강제 여부, 패키지(ai·pdf, mm 사이즈) 이름 규칙, 로고·렌더이미지·관련서류
- 알림 방식(단톡방·노션)을 붙일지
- 아이디어 2(카페24 상세페이지 자동 업로드)와 어떻게 이어질지. 이 도구가 "현재 썸네일·상세페이지"를 폴더만 보고 알 수 있게 만들어 두면 이어 붙이기 쉬움 (제안)
